Ici vous y retrouverez l'intégralité de mes projets universitaires m'ayant permis d'accroître mes compétences de développement informatique.

## SQL, Python - Création et exploitation d'une base de données :

Mon projet dont je suis le plus fier, il s'est déroulé en 3 étapes, la création, l'alimentation et l'étude de base de données.

### Première partie :

En partant d'un schéma UML, j'ai implémenté le schéma de la base de données qui m'a été donnée par mes professeurs. J'ai dû prendre en compte les différentes multiplicités entre les tables afin de définir les tables associations et clés étrangères nécessaires à sa réalisation.

### Deuxième partie :

En repartant d'un schéma créé par mes professeurs, j'ai peuplé ce schéma regroupant des centaines de données à l'aide de multiples requêtes SQL que vous pourrez retrouver dans cette partie.

### Troisième partie :

Repartant de la deuxième partie du projet, cette partie consistait à étudier les données de ce schéma, à l'aide de librairies Python.
